# 次フェーズ第1段階 — 実機確認手順

対象はスマートフォンの通常ブラウザ。可能なら iPhone の Safari と Android の Chrome でそれぞれ確認する。現時点では自動のブラウザ E2E テストがないため、確認結果をこの一覧に沿って報告する。問題の再現には画面のシードコードを控える。

## 遊びやすさ

1. 縦向きで開き、READY の OK、盤面、時間、ミス・ヒント数、主操作が不自然な横スクロールなしで使えるか確認する。
2. 各難易度で新しい問題を3回ずつ生成する。待ち時間が長い・同じ形が続く・表示評価が選択難易度と大きくずれる場合は、端末名、ブラウザ、シード、概算待ち時間を記録する。
3. タップで `×` の付け外し、ドラッグで連続入力、長押し後に離してタコ確定、長押し中にセル外へ移動してキャンセル、ダブルタップのショートカットを試す。誤タップやブラウザのズーム・コンテキストメニューが妨げないか確認する。
4. 一時停止・再読み込み・復帰で READY 中の時間が加算されないか、盤面・マーク・ミス・ヒントが残るか確認する。

## ヒントとポップアップ

1. ヒントを開く。最初は注目箇所だけが示され、結論・対象の `×` がすぐには見えないことを確認する。「次のヒント」で段階が進み、最後に理由と対象セルが分かることを確認する。
2. `×を適用` が出るヒントでは、最後の段階で押し、対象の `×` だけが追加されることを確認する。タコを示すヒントでは自動配置されず、長押しで確定する案内があることを確認する。
3. 同じ盤面でヒントを閉じて再度開き、同じヒントならヒント使用数が増えず、開示段階が保たれることを確認する。
4. 誤った `×` を付けてヒントを開き、矛盾が優先されることを確認する。最後の段階まで進めると、1つ外すだけで解決する `×` がある場合はそのセルが強調されることを確認する。
5. 外付けキーボードがあれば、ポップアップを開いた後の Tab / Shift+Tab が中で循環すること、Escape で閉じて元の操作へフォーカスが戻ることを確認する。可能なら VoiceOver / TalkBack でタイトルと操作が読めるか確認する。

## 設定と成績

1. 振動設定を切り替え、対応端末で操作時の振動が有効・無効になること、再読み込み後も設定が残ることを確認する。非対応端末でエラーが出ないことも確認する。
2. 問題をクリアし、結果ポップアップの内容、ローカル順位、履歴、最近のシードからの復元を確認する。再読み込みで同じクリアが重複しないことを確認する。

## 報告用メモ

- READYダイアログの下の影スタイルが不自然なのでなくしたい
- タコを設置する長押しはもう少し早くして良い
  - 太枠を出すのにアニメーションを付ける
- 問題を変えた時に盤面が画面の中央にくるようスクロール
- クリアダイアログ表示でもう少し派手なエフェクト(紙吹雪？)をつける
  - 次の問題へ行く時に難易度を変えたい

## 追記への対応と再確認

- READY カードのオレンジ色の下影を削除した。
- 長押し成立を 520 ms から 420 ms に短縮し、太枠が出るときに短いアニメーションを追加した。ドラッグやセル外キャンセルとの誤判定がないか再確認する。
- 新しい問題とシード復元の後、盤面を画面中央へスクロールするようにした。READY を閉じたあとも位置が保たれるか確認する。
- クリア時に控えめな紙吹雪演出を追加した。動きを減らす設定では表示しない。結果ダイアログ内で次の難易度を選び、その難易度で次の問題が始まるか確認する。

上記はコード上で対応済み。ユーザーから、基本動作に問題がないことを確認済み。

## 追加の再確認

- クリア時の紙吹雪をダイアログより手前に表示するよう変更した。紙吹雪が見えること、ボタンのタップを妨げないことを確認する。
- `×` が付いたセルを長押ししても太枠・タコ・ミスが出ず、`×` も残ることを確認する。短いタップでは従来どおり `×` を外せることを確認する。

ユーザーから、追加調整後の紙吹雪と `×` 上の長押し動作を確認済みとの報告あり。端末・ブラウザの詳細、外付けキーボード、VoiceOver / TalkBack での確認結果は未記録のため、支援技術の確認は継続課題とする。
